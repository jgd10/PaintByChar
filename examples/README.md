Examples for PaintByChar

Files:
- basic_example.py: simple string_to_image using a preset
- file_example.py: writes a small grid to a file then calls file_to_image
- styles_example.py: shows the three RenderStyle modes
- preset_example.py: prints available presets and saves a preset-based image

Run examples from the repository root: python examples\basic_example.py
They add src/ to sys.path so paintbychar.py is imported directly.
