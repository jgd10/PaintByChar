# Security policy

## Supported versions

The project currently supports the latest released version and the default branch.

If a vulnerability is discovered in an older release, we may provide a fix depending on the severity and maintainability of the affected code.

## Reporting a vulnerability

Please do not open a public GitHub issue for security-sensitive problems.

Instead, report vulnerabilities privately by emailing the maintainer:

jgd10.github@gmail.com

Please include:

- a description of the issue
- steps to reproduce it
- affected versions
- any suggested mitigation or fix

We will acknowledge receipt as soon as possible and work toward a resolution in a timely manner.

## Disclosure policy

We ask that reporters allow a reasonable period for remediation before public disclosure. Once a fix is available, we may coordinate a public advisory or release note.
